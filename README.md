# Software Development Associate's Degree: Exercise Lists
![C](https://img.shields.io/badge/C-054096?style=for-the-badge&logo=c&logoColor=white)

This repository contains my solutions to the **Algorithms and Programming Logic** exercise lists, set by Professor Fabio Gomes at the Federal Institute of Paraíba (IFPB).

## Repository Structure

The exercises are organised into folders by topic:

| Folder | Topic | Concepts covered |
|--------|-------|------------------|
| 📁 `input-output` | Input and output | Data types, `printf`, `scanf`, etc. |
| 📁 `conditionals` | Conditional statements | `if`, `else if`, `else` |
| 📁 `loops` | Repetition structures | `for`, `while`, `do-while` |
| 📁 `vectors-matrices` | Arrays | Vectors and matrices |
| 📁 `subprograms` | Subprograms | Functions and procedures |
| 📁 `recursion` | Recursion | Functions that call themselves |

## How to Run

The examples are written in C. To compile and run a solution:

```bash
gcc exercise.c -o exercise
./exercise
```
